# CanTrack — ניהול מכונת פחיות

אפליקציית Android בעברית (RTL), שעובדת ללא אינטרנט. הנתונים נשמרים מקומית ב-WebView באמצעות localStorage.

## תכונות
- ניהול מוצרים, עלות, מחיר מכירה, מלאי וסף מלאי נמוך
- רישום מכירות עם עדכון מלאי וחישוב רווח גולמי
- רישום קניות מספק והוצאות עסקיות
- דשבורד וסטטיסטיקות, מוצר נמכר ביותר וגרף הכנסות לשבעה ימים
- ייצוא גיבוי JSON, שחזור גיבוי וייצוא פעולות CSV

## בניית APK דרך GitHub Actions
1. העלו את כל תכולת התיקייה הזו לענף `main` במאגר `yemen-champ/App`.
2. פתחו בלשונית **Actions** את `Build CanTrack APK`.
3. המתינו לסיום מוצלח של `Build debug APK`.
4. פתחו את ריצת ה-workflow והורידו את ה-artifact בשם `CanTrack-debug-apk`. בתוך הקובץ נמצא `app-debug.apk`.
5. זהו APK מסוג debug להתקנה ובדיקה. להפצה ציבורית יש להגדיר חתימת release.

## הערות חשובות
- הפרויקט לא מבצע תקשורת רשת בזמן ריצה; GitHub Actions זקוק לאינטרנט רק בזמן בניית האפליקציה.
- הנתונים נשמרים במכשיר בלבד. ייצאו גיבוי JSON באופן קבוע; מחיקת נתוני האפליקציה או הסרתה עלולות למחוק את המידע.
- מכירות אינן מתקבלות אוטומטית ממכונת הפחיות. יש לרשום אותן ידנית, אלא אם בהמשך יתווסף חיבור למערכת המכונה.
- בדיקה אוטומטית של קומפילציית Android לא הורצה בסביבת יצירת המקור הזו.
